TUTORIAL: OPTIMASI HARDWARE UNTUK YOLOv8 (NVIDIA & INTEL)
=========================================================

Sistem pendeteksi keramaian ini telah dilengkapi dengan fitur "Auto-Detection Hardware".
Program akan otomatis memilih hardware tercepat yang Anda miliki dalam urutan prioritas berikut:

1. NVIDIA GPU (CUDA) - Sangat Cepat
2. Intel HD/UHD iGPU (OpenVINO) - Cepat
3. Intel CPU (OpenVINO) - Lumayan Cepat
4. CPU Standar - Lambat

---------------------------------------------------------
BAGIAN A: PENGGUNA GPU NVIDIA (GTX, RTX, MX, dll)
---------------------------------------------------------
1. Hapus versi PyTorch lama (agar tidak bentrok):
   pip uninstall torch torchvision torchaudio ultralytics -y

2. Buka terminal di dalam folder "server" dan install PyTorch CUDA 12.1:
   pip install -r requirements-gpu.txt

[KHUSUS PENGGUNA WINDOWS]
Jika setelah menjalankan perintah di atas YOLOv8 masih berjalan di CPU (tidak mendeteksi CUDA), hapus PyTorch lama dan install ulang secara paksa menggunakan perintah ini di Command Prompt / PowerShell:
   pip uninstall torch torchvision torchaudio -y
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

---------------------------------------------------------
BAGIAN B: PENGGUNA LAPTOP/PC INTEL (Tanpa VGA NVIDIA)
---------------------------------------------------------
Jika Anda menggunakan laptop/PC bertenaga Intel (Gen 6 ke atas) dan hanya memiliki Intel HD/UHD/Iris Graphics, ikuti langkah ini:

1. Install library OpenVINO:
   pip install openvino

2. Jalankan server seperti biasa (python main.py). 
   (Catatan: Saat pertama kali dijalankan, program akan memakan waktu sekitar 1 menit untuk mengkonversi model YOLO menjadi format khusus Intel (OpenVINO). Proses ini normal dan hanya terjadi SATU KALI saja).

---------------------------------------------------------
BAGIAN C: MENGAKTIFKAN INTEL iGPU DI LINUX (OPSIONAL)
---------------------------------------------------------
Jika Anda menggunakan OS Linux (seperti Ubuntu, Fedora, Arch) dan ingin OpenVINO berjalan maksimal menggunakan GPU Bawaan Intel (iGPU), ada DUA LANGKAH WAJIB yang harus dilakukan. Jika tidak dilakukan, OpenVINO hanya akan membaca Intel CPU Anda.

LANGKAH 1: INSTALL DRIVER KOMPUTASI (OPENCL)
Jalankan salah satu perintah berikut di Terminal sistem Anda sesuai distro:
- Ubuntu/Debian/Mint: sudo apt-get install intel-opencl-icd
- Fedora/RHEL:        sudo dnf install intel-compute-runtime
- Arch/Manjaro:       sudo pacman -S intel-compute-runtime

LANGKAH 2: MEMBERIKAN HAK AKSES (GROUP PERMISSION)
Di Linux, user biasa dikunci dari akses GPU secara langsung. Anda harus memasukkan user Anda ke grup "video" dan "render":
   
   sudo usermod -aG video,render $USER

SANGAT PENTING: Setelah menjalankan perintah di atas, Anda WAJIB me-restart (reboot) komputer/laptop Anda agar perizinannya aktif!

---------------------------------------------------------
CARA MENGETES HARDWARE (TESTER)
---------------------------------------------------------
Anda bisa menjalankan file "test_hardware.py" di dalam folder server:
   
   cd server
   python test_hardware.py

Output akan memberitahu Anda secara pasti hardware apa yang sedang aktif dan berhasil dideteksi oleh sistem!
